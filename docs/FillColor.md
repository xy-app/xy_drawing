# 区域填充与打码脱敏 (FillColor)

对目标图像的指定矩形区域进行纯色遮罩、马赛克像素打码或柔化模糊处理。是 RPA 自动化处理证件照片（身份证号/姓名遮蔽）、银行卡号、手机号与财务敏感数值的关键隐私合规节点。

## 权限要求
> 无要求

## 子流程
> 不支持

## 运行参数

* `image` (Image)：待处理目标底图，支持变量、文件路径或 Base64。
* `rect` (String)：遮罩与打码的目标区域，支持 `[x, y, w, h]` 数组或 `"x, y, w, h"` 字符串（如 `"50, 80, 240, 40"`）。
* `mode` (String)：脱敏模式，可选 `solid` (纯色色块遮罩)、`mosaic` (像素马赛克打码)、`blur` (区域柔化模糊)。
* `color` (String)：仅在 `solid` 纯色模式下生效的填充颜色（如 `black`、`white`、`#1F2937`），默认 `black`。
* `block_size` (Number)：马赛克像素块或模糊核大小（像素），数值越大遮蔽程度越深，默认 `10`。
* `output_path` (String)：可选。输出图像保存路径。

## 输出
> 返回脱敏处理后的图像对象，类型为 `image`。

## 示例
```json
{
  "image": "$id_card_img",
  "rect": "180, 220, 280, 35",
  "mode": "mosaic",
  "block_size": 10
}
```
